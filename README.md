# Sagarmatha Engineering College website redesign

Responsive homepage redesign retaining the original college's headings, program names, section content, notices/events, student testimonial, alumni stories, why Sagarmatha features, video tour, sister concerns and contact details.

Built with static HTML, CSS and vanilla JavaScript; no build step. Official pages are linked for detailed program, notice, gallery, video and admission content.

**Media note:** This version uses illustrative photography in some visual blocks. The original WordPress media-library image files were not available through the repository or page text extraction during this update. Replace these illustrative images with the exact original SEC media assets before treating the redesign as a complete photo-for-photo migration.
